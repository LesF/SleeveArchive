# SleeveArchive Album Catalog

## Inspiration for creating this app
While I have a pretty good recollection of which albums I own, I wanted to create a catalog of my
vinyl collection.  There are some tattered sleeves and well aged records, which I may want to replace,
and a few classics I would love to add to my collection.  When I'm wandering through a record
store, I'm hoping this simple app will give me some guidance.

## What it does
The cool [MusicBrainz](https://musicbrainz.org/) API allows me to search for albums, add them to my
collection, get cover art, and link to the MusicBrainz page for full album details, lyrics etc.

## Support
This is a personal project, I don't expect it to pay my mortgage, but if you want to give support,
I prefer you to go to [MusicBrainz](https://musicbrainz.org/) and hit the donate button.  It's that
encyclopedic database which makes this app possible.
